# BORO 1.5 — асуултад шууд хариулах

- **A–D заавал шаардахгүй.** Энгийн асуулт, дугаартай/дутуу сонголт, OCR-д сонголтын үсэг эвдэрсэн текстийг утгаар нь боловсруулна. A–D бүтэн үед шалгагдсан сонголтын горим хэвээр. Харагдаагүй сонголтын үсгийг зохиохгүй байх заавартай.
- **Текстээр асуух:** үндсэн цонхны товчоор асуултаа бичих, хуулж тавих, OCR текстээ засаж хариу авах боломжтой. Модель бэлэн бол дэлгэц сонгох шаардлагагүй. Энэ цонх нээхэд автомат хяналт зогсоно; дараа нь Эхлэх дарж үргэлжлүүлнэ. Cloud сонгосон үед илгээх үйлчилгээ, төлбөрийн тайлбар харагдана; өөр үйлчилгээ рүү автоматаар шилжихгүй.
- **OCR сэргэлт:** нийт 6с дотор дэвсгэр хэвийн болгох, томруулсан sparse layout, босгоор ялгасан block layout гэсэн 3 хүртэл оролдлого. Хоосон/утгагүй текстэд AI хариу зохиохгүй. 2 тогтвортой уншилт, OCR confidence ≥45 үед боловсруулна; <70 бол хариунд уншилтыг нягтлах тэмдэглэгээ нэмнэ. Эдгээр нь хэмжиж баталгаажуулсан магадлал биш.
- Математик оператор болон аравтын цэг cache түлхүүрт хадгалагдана: `2+2`, `2-2`, `1.5`, `15` нь тусдаа асуулт.
- Windows build нь энгийн асуултын локал AI smoke болон цайвар/бараан 4 төрлийн жишээний OCR+AI benchmark ажиллуулна. `ocr_exact` талбар нь эхтэй тэмдэгт хүртэл таарсан эсэхийг тусад нь харуулна. Зөв хариу гарсан нь OCR яг зөв уншсан гэсэн баталгаа биш.
- Бүх зураг, бүдэг текст, гар бичмэл, математик тэмдэгтийг алдаагүй унших эсвэл CPU дээр 10с дотор хариулах баталгаа байхгүй. Уншилт муу үед Текстээр асуух нь OCR-ийг тойрч шууд асуултаар ажиллана.

Доорх хэсгүүд нь өмнөх хувилбаруудын тайлбар; A–D/70%/хоёр оролдлогын хуучин хязгаарыг дээрх 1.5 өөрчлөлт орлоно.

# OCR сэргэлт ба үндсэн цонхны түүх

- OCR нэг удаагийн 2 секундийн хатуу хязгаараас нийт 6 секундийн төсөвтэй хоёр оролдлого руу шилжив. Эхний layout timeout болсон ч sparse-text горимоор дахин оролдоно. Dark background-ийг fallback дээр хөрвүүлж, том зураг болон upscale хэмжээг хязгаарлана. Хурдан амжилттай уншилтад fallback зураг боловсруулахгүй.
- Дутуу OCR текст үндсэн асуултын хэсэгт харагдана; өмнөх хариуг устгахгүй. Хөдөлгүүрийн эхлэлт болон timeout-д Монгол тайлбар гарна. A–D бүрэн, хоёр тогтвортой уншилт, confidence ≥70 шаардлага хэвээр.
- Хариултын түүх үндсэн цонхонд асуулт, бүх сонголт, хариу, эх сурвалж, хугацаатайгаа бүтнээр харагдана. Тусдаа цонх нээхгүй, хулганаар гүйлгэж уншина. Дискэнд хадгалсан сүүлийн 200 бичлэг дахин нээхэд сэргээнэ.
- Хүлээгдэж буй хамгийн сүүлийн тогтвортой асуулт өмнөх AI хүсэлт дуусмагц шинэ OCR хүлээлгүй эхэлнэ. Нэг AI хүсэлт зэрэг ажиллана; шинэ асуултын хүсэлтийн төсвийг хуучин хүсэлтийн хүлээлт дуусгахгүй.
- Windows OCR child process-д CREATE_NO_WINDOW дээр нэмээд STARTF_USESHOWWINDOW / SW_HIDE хэрэглэнэ. Энэ өөрчлөлт суусан хуучин EXE-д автоматаар орохгүй; шинэ Windows build амжилттай гарсны дараа шинэ суулгагч хэрэгтэй.
- 10 секунд нь зорилт: бодит Windows CPU, OCR, API хугацааг энд хэмжээгүй. OCR хүртэл 6с, AI хүсэлт хүртэл 30с тул 10с баталгаа биш. Linux unit шалгалт Windows дэлгэц, console болон бодит Монгол OCR-ийн баталгаа биш.

# BORO — тасралтгүй хяналт, хариултын түүх

- Windows дээр Tesseract-ийн OCR, хэл болон хувилбар шалгах бүх child process-д `CREATE_NO_WINDOW` тохируулсан. Хэл шалгалтыг cache-лана.
- Эхлэх → Зогсоох хүртэл хяналт үргэлжилнэ. AI ажиллаж байх үед OCR шинэ асуултыг уншсаар байна. Нэг AI хүсэлт зэрэг ажиллана; дуусмагц одоо харагдаж буй хамгийн сүүлийн тогтвортой асуултыг боловсруулна. Шинэ асуулт гарсан бол хуучин хариуг одоогийн асуулт дээр тавихгүй, түүхэнд үлдээнэ.
- Сүүлийн 200 асуулт, A–D сонголт, хариу, үндэслэл, эх сурвалж, хугацааг `%LOCALAPPDATA%\TeamsAI\answers.json` файлд хадгалж дахин нээхэд сэргээнэ. Түүхийг үндсэн цонхонд бүтнээр нь гүйлгэж уншина. Энэ файл энгийн локал JSON; асуулт/хариуг хадгалдаг, зураг болон API түлхүүр агуулахгүй. Устгах бол аппыг хаагаад файлыг устгана.
- Шинэ суулгалтын унших завсар 1 секунд, OCR оролдлогын нийт төсөв 6 секунд. Хуучин тохиргооны завсар хадгалагдана; хурдан горимд Тохиргоо → 1 секунд сонгоно.
- **10 секундийн зорилт**: хугацааг интерфэйст харуулна. Удаан локал CPU/API үед 10 секундийг батлахгүй; үр дүнг байнга тасалж алдахгүйн тулд AI хүсэлтэд нийт 30 секунд хүртэл төсөв үлдээсэн. Timeout/алдааны дараа автоматаар дахин оролдоно; өмнөх 60 секундийн хоригийг арилгасан. Эхний модель ачаалалт, polling-оос өмнөх хугацаа болон өөр хүсэлтийн хүлээлт нь зорилтыг сунгаж болно.
- Linux mocked/unit шалгалт Windows GUI/console болон бодит Teams хурдны баталгаа биш. Windows workflow installer болон native smoke шалгалтыг ажиллуулна.

# BORO 1.4 — AI Settings

Settings → AI үйлчилгээ: **local / gemini / openai / grok**. Локал горим анхдагч хэвээр. Cloud ашиглах бол өөрийн үйлчилгээний API түлхүүр, тухайн бүртгэлд нээлттэй моделийн нэрийг оруулж Хадгалах дарна. OpenAI API нь ChatGPT Plus эрхээс тусдаа; Gemini/Grok-ийн тариф, лимит тухайн бүртгэлээс хамаарна. Программ бүх API-г үнэгүй гэж үзэхгүй.

- Түлхүүр Windows Credential Manager эсвэл macOS Keychain-д хадгалагдана. Native vault нээгдэхгүй бол файлд нөөцлөхгүй, алдаа харуулна. Windows/macOS-ийн өөрийн нэвтрэх/зөвшөөрөх цонх гарч болно.
- API түлхүүрийн талбар масктай; хадгалсан түлхүүрийг дэлгэцэд эргүүлж харуулахгүй. Хоосон үлдээвэл өмнөх түлхүүр хэвээр. Устгах товч зөвхөн сонгосон үйлчилгээний түлхүүрийг устгана.
- Хадгалсан түлхүүрээр холболт шалгах нь 2+2 гэсэн зохиомол асуултыг зөвшөөрсний дараа илгээнэ. Тариф/лимит хэрэглэгдэж болно. Дэлгэцийн мэдээлэл тест хүсэлтэд орохгүй.
- Cloud горимд Эхлэх дарахад OCR асуулт, A–D сонголт болон олдсон хуулийн заалт тухайн үйлчилгээ рүү илгээгдэхийг нэг удаа батална. Зураг илгээхгүй. Автоматаар өөр үйлчилгээ/төлбөртэй fallback руу шилжихгүй.
- Тохиргоо солиход өмнөх саналын cache цэвэрлэгдэнэ. Локал сонголтод буцахад дахин модель ачаалж болно; cloud-оор нээхэд локал модель ачаалахгүй.
- settings.json/audit-д түлхүүр бичихгүй. API алдааны body/header/key-г хэвлэхгүй; 401/403/404/429-д товч тайлбар харуулна. HTTPS endpoint-үүд тогтмол, redirect зөвшөөрөхгүй. Certifi CA root санг багцалж TLS certificate/hostname шалгалтыг асаалттай байлгана; Mac дээр гаднын Python certificate файл шаардахгүй. Uninstall нь OS-ийн түлхүүрийг автоматаар устгахгүй; устгах бол эхлээд Settings дотроос устгана.

Cloud хүсэлтийн бүтэц, алдаа, redaction, timeout нь mocked HTTP tests-ээр шалгагдана. Бодит Gemini/OpenAI/Grok хүсэлтээр шалгах түлхүүр өгөөгүй тул live API амжилттай холбогдсон гэж үзэхгүй. Windows build дээр native Credential Manager-д жинхэнэ түлхүүр биш test fixture хадгалж/уншиж/устгах шалгалт ажиллана. Mac дээр frozen native Keychain backend импорт шалгана; хэрэглэгчийн Keychain consent/storage болон бодит API-ийг тусад нь шалгах шаардлагатай.

API баримт: https://developers.openai.com/api/docs/guides/structured-outputs ; https://ai.google.dev/gemini-api/docs/generate-content/structured-output ; https://docs.x.ai/developers/model-capabilities/text/structured-outputs . Model нэр Settings-д өөрчлөгдөнө; үйлчилгээний model availability-г өөрийн бүртгэл дээр шалгана.

# BORO — Монгол Quiz туслах 1.3

![BORO](branding/boro-logo.svg)

Teams Quiz-ийн нэг асуулт болон A–D сонголтыг Монгол кирилл OCR-оор уншина. Асуулт/сонголтыг ялгаж, сонголтын санал, 1–2 өгүүлбэрийн үндэслэл, өндөр/дунд/бага итгэлцэл харуулна. Итгэлцэл нь моделийн өөрийн үнэлгээ бөгөөд хэмжиж баталгаажуулсан магадлал биш. Дутуу/давхар асуулт танигдвал AI руу явуулахгүй; хэсгээ дахин сонгохыг анхааруулна. Кирилл АБВГ болон Latin A–D дэмжинэ. OCR confidence нь AI confidence-ээс тусдаа.

Эхний OCR capture эхэлснээс 30 секундийн төсөв тавина: хоёр удаагийн тогтвортой OCR, завсар, хайлт болон AI хүсэлт орно. Үлдсэн хугацааг HTTP timeout-д өгнө, хоцорсон саналыг харуулахгүй. Шинээр асаах модель ачаалалт, дэлгэц унших polling interval-аас үүдэх асуулт илрүүлэхийн өмнөх хоцролт энэ хэмжилтэд орохгүй. Тиймээс дэлгэц дээр үнэхээр гарснаас 30с дотор гэдгийг үүгээр батлахгүй. Дахин давтагдсан асуултын саналыг cache-аас шууд харуулна. OCR, model, төхөөрөмжийн хурднаас шалтгаалан зорилт биелэхгүй байж болно.

`benchmark-results.json` нь CI дээр бодит OCR+локал модель ашигласан 2 synthetic жишээний хугацаа/зөв сонголтыг бүртгэнэ. Зорилт биелээгүй бол ч үр дүнг нуухгүй; installer шалгалт нь энэ жижиг benchmark-ийн чанарын баталгаа биш. Монгол хууль болон бодит Teams дээр 20+ асуултаар p50/p95, accuracy-г тусад нь хэмжих шаардлагатай.

BORO лого: SVG; icon PNG/ICO/ICNS нь build дээр нэг скриптээс үүснэ. Windows болон Mac-ийн багцууд тусдаа, Python/OCR/локал модель хамт багтана. Хуучин TeamsAI releases-ийг орлуулахгүйгээр шинэ BORO хувилбар бэлтгэж байна. macOS app нэр `BORO.app`, Windows `BORO.exe`. Түүх хадгалах хуучин TeamsAI data directory-г нийцтэй байлгасан.

Программ зөвшөөрөлгүй санал сонгож/илгээхгүй. Хэрэглэгч AI-ийн санал болон үндэслэлийг нягталж Teams дээр өөрөө сонголт хийнэ. API түлхүүр шаардлагагүй. Нэг зөв хариулттай A–D Quiz бол энэ хувилбарын үндсэн горим; олон зөв хариулт болон зурагтай асуултад найдвартай ажиллана гэж үзэхгүй.

# TeamsAI — Дэлгэцийн Монгол AI туслах

Жижиг Монгол интерфэйс: **Хэсэг сонгох → Эхлэх → хариуг унших**. 460×680 цонх, харанхуй загвар, тусдаа тохиргоо. Хэрэглэгч Python, OCR, Ollama болон модель тусад нь суулгахгүй. Windows суулгагчид бүх runtime болон Qwen3 4B Q4_K_M модель багтана. API түлхүүр, төлбөрт API байхгүй.

## Татах / суулгах
[Releases](https://github.com/ssboroo/teamsai/releases) хэсгийн хамгийн сүүлийн амжилттай build-ийн **TeamsAI-Setup.exe болон бүх .bin** файлыг нэг хавтаст татна. EXE-г ажиллуулж суулгана. Бүх хэсэг хэрэгтэй; эдгээр нь нэмэлт программ биш, нэг суулгагчийн өгөгдөл. Модель хэдэн GB тул таталт том. Release байхгүй бол Windows build хараахан амжилттай болоогүй гэсэн үг; эх кодыг бэлэн суулгагч гэж үзэхгүй.

Windows 10/11 x64, AVX2 дэмждэг Intel/AMD CPU; 16GB RAM санал болгоно, сул диск 8GB орчим байлга. AVX2-гүй хуучин төхөөрөмж, ARM64 дэмжлэгийг шалгаагүй. Эхний модель ачаалалт 150 секунд хүртэл хүлээж болно. Суулгасны дараа сүлжээ шаардлагагүй. CPU хурднаас хамаарч 30 секундийн зорилт биелэхгүй байж болно.

## Ашиглах
1. Teams-ийн асуулт, бүх сонголтыг дэлгэцэд гаргаж томруулна.
2. TeamsAI-г асуултын гадна байрлуулна. **Хэсэг сонгох** товчоор асуулт, сонголтуудыг хүрээлнэ. Esc цуцална.
3. **Эхлэх** дарж локал боловсруулалтыг нэг удаа зөвшөөрнө.
4. Хоёр уншилт ижил, OCR confidence ≥70 бол автомат хариу гарна. Монгол Ө/Ү, үгүйсгэл, тоог OCR буруу уншиж болох тул эх текстийг харна.
5. Шинэ асуулт гарвал дахин уншина. **Зогсоох** дарвал дараагийн үр дүнг дэлгэцэд гаргахгүй; явж буй локал хүсэлт timeout хүртэл дуусаж болно.
6. Хуулахад зөвшөөрөл асууна. Teams-д хариу сонгож илгээхийг хэрэглэгч хийнэ.

## Монголын хуулийн асуулт
Модель нь Монгол хуулийн баталгаажсан бүрэн сан биш. Сангүй үед хариуг **БАТАЛГААЖААГҮЙ** гэж тэмдэглэнэ. Тохиргоо → Хуулийн сан нэмэх хэсэгт JSON импортолно. Мөр бүр `title`, `article`, `text`, `source`, `verified_on`, `status` талбартай; `status=active` мөрийг ашиглана. Эх заалтыг legalinfo.mn-ээс хүн нягталж оруулна. Lexical/prefix хайлт утга ойролцоо өөр үгтэй заалтыг алдаж болно; citation индекс шалгах нь хариуны үнэн зөвийг батлахгүй. Хуулийн эх, хүчинтэй байдлыг өөрөө шалгана. Энэ репо бодит хуулийн бүрэн корпус агуулахгүй.

## Нууцлал
Дэлгэц зөвхөн сонгосон хэсгээр уншигдана. Зураг хадгалахгүй. Модель localhost дээр санамсаргүй порт, нэг удаагийн токентой ажиллана; HTTP proxy ашиглахгүй. Программ хаагдахад өөрийн AI процессыг зогсооно. API түлхүүр шаардлагагүй. `%LOCALAPPDATA%\TeamsAI` дотор тохиргоо, импортолсон хууль, эргэлттэй audit log хадгална. Audit нь асуултын hash, хугацаа, алдааны төрөл; асуулт/хариу/зураг бичихгүй. Clipboard-д хуулсан текст бусад аппад харагдаж болно. Uninstall хэрэглэгчийн хуулийн санг хадгална.

## Хөгжүүлэгч build
Windows build agent-д Python 3.11, Tesseract 5 (Chocolatey tesseract), Inno Setup 6 хэрэгтэй. `scripts/installer_language.ps1`, дараа `build.ps1` ажиллуулна. Хэрэглэгчид эдгээрийг тусад нь суулгахгүй. Build нь upstream CPU engine, Qwen GGUF, mon+eng traineddata татаж asset manifest-д хувилбар/эх URL/SHA256 бүртгэнэ. Model LFS SHA, engine release digest байгаа үед шалгана. Runtime DLL, лицензийн текстүүд багцлагдана. Upstream release болон tessdata-г build эхлэхэд resolve хийдэг тул бүрэн reproducible lock биш. Build алдаа гарвал нийтлэхгүй.

GitHub Actions дарааллаар unit tests, бодит synthetic Mongolian OCR + model smoke, PyInstaller frozen smoke, Inno installer, silent install + installed smoke + uninstall ажиллуулсны дараа л release гаргана. Эдгээр нь бодит Teams/Монгол хууль accuracy benchmark биш. Code signing тохируулаагүй.

## Баталгаажуулалтын төлөв
Локал Linux дээр unit tests/compile шалгаж болно. Windows workflow-ийн бодит дүнг [Actions](https://github.com/ssboroo/teamsai/actions)-аас харна. Workflow дуусаагүй байхад суулгагч бүтсэн гэж үзэхгүй. Хүний шалгах зүйл: Windows GUI харагдах байдал, Teams dark/light, DPI 100/125/150%, Ө/Ү OCR, 20+ асуултын зөв хариу болон нийт latency p50/p95.


## Унших гурван горим
- **Дэлгэцийн хэсэг:** хамгийн хурдан, асуулт/сонголтоо хүрээлнэ.
- **Программын цонх:** Teams эсвэл browser-ийн нээлттэй цонхыг жагсаалтаас сонгоно. Байрлал/хэмжээг уншилт бүрт дагана. Цонх харагдаж, халхлагдаагүй байх ёстой; minimize хийвэл уншихгүй.
- **Бүтэн дэлгэц:** бүх мониторын харагдах пикселийг уншина. Өөрийн TeamsAI цонхыг Windows capture exclusion-аар хасна; хасах боломжгүй системд энэ горимыг зогсоож хэсэг сонгохыг санал болгоно. Их тексттэй үед удаан/буруу асуулт унших эрсдэлтэй.

Browser-ийн зөвхөн харагдаж буй tab уншигдана. Далд tab, minimize цонх, халхлагдсан browser-ийг DOM/accessibility API-р унших боломж хэрэгжүүлээгүй. Тестийн хариуны `Хариулт:` мөрийг томоор үзүүлнэ; AI-ийн сонголт зөв гэсэн баталгаа биш. Таймер өөрчлөгдөх зэрэг OCR текст тогтворгүй бол автоматаар хариулахгүй тул асуулт/сонголтоор хүрээлнэ.

## macOS — Windows-ийг орлуулахгүй нэмэлт хувилбар
Apple Silicon (arm64) болон Intel (x64) тусдаа багцтай. Python, Tesseract mon+eng, локал Qwen модель, native dylib-ууд .app-д багтана. Windows-ийн `build-*` releases хэвээр; Mac-ийн `mac-arm64-*`, `mac-x64-*` tags тусдаа.

Releases дахь өөрийн архитектурын бүх `.pkg.partNN`, `Install-TeamsAI-ARCH.command`-ийг нэг хавтаст татаж command-г ажиллуулна. Энэ нь хэсгүүдийг нэгтгэж SHA256 шалгаад macOS Installer нээнэ. Downloaded command executable биш бол Terminal-д `chmod +x` өгч болно. Эсвэл Actions artifact ZIP-ийг задлаад доторх бүтэн `.pkg`-г шууд нээнэ. Админ зөвшөөрөл /Applications-д суулгахад хэрэгтэй.

**System Settings → Privacy & Security → Screen Recording / Screen & System Audio Recording** хэсэгт TeamsAI-г зөвшөөрөөд аппыг дахин нээнэ. Энэ нь macOS-ийн зөвшөөрөл; программаас тойрохгүй. Mac дээр бүтэн дэлгэц үндсэн мониторынх; app цонх capture хийх агшинд богинохон нуугдаж буцна. Цонх сонгох, дэлгэцийн хэсэг сонгох боломжтой. Харагдаагүй browser tab уншихгүй.

Ad-hoc signing нь Developer ID signing болон Apple notarization биш. Gatekeeper автоматаар итгэх баталгаа байхгүй; эх сурвалжийг нягталж macOS-ийн ердийн зөвшөөрлийн урсгалаар нээнэ. Энд Gatekeeper/TCC-г унтраадаг арга агуулаагүй. `~/Library/Application Support/TeamsAI` дотор тохиргоо, хууль, audit хадгална. Устгахдаа Applications-аас TeamsAI.app-ийг хогийн саванд хийнэ. Модель болон сангийн чанар/хурдны хязгаарлалтууд Windows-тэй адил.

Mac workflow нь package бүтээх, synthetic Монгол OCR, локал модель, frozen app болон суусан .app smoke-ийг шалгана. Screen Recording permission, Retina/multi-monitor, бодит Teams UI-г хэрэглэгчийн Mac дээр хүн шалгах шаардлагатай. CI-ийн амжилт нь эдгээрийг шалгасан гэсэн үг биш.
